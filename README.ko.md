# 유럽 축구 경기기록 기반 경기 운영 유형 분석

**승패를 넘어 팀의 경기 내용을 어떻게 유형화할 수 있으며, 그 유형은 리그와 시즌에 따라 어떻게 분포할까요?**

[English](README.md) · [문제 정의](docs/PROBLEM_DEFINITION.md) · [검증 기록](docs/VALIDATION.md) · [업로드 판단](docs/PUBLICATION_PLAN.ko.md)

엄민섭의 석사학위논문 **「축구 경기기록 기반 전술 유형 군집화와 유형별 경기기록 특성 분석: 유럽 5대 리그를 중심으로」(2026)**를 바탕으로 구성한 연구 포트폴리오입니다.

팀-경기 단위의 기록을 유형화하고, 유형의 특징과 리그·시즌별 분포를 설명합니다. 논문의 ‘전술 유형’은 경기기록의 통계적 패턴을 뜻합니다. 포메이션, 감독의 의도, 전술의 효과를 직접 측정한 것은 아닙니다.

> **공개 상태 — 2026년 10월 8일, 검증 범위를 명시한 연구 아카이브.** 저장된 CSV를 검사하고 요약값을 다시 계산했습니다. 기존 노트북 3개는 처음부터 끝까지 재실행하지 않았습니다. 두 군집의 사례 수가 논문 표 8과 달라 아래에 두 값을 구분했습니다. 논문 전체를 동일하게 재현했다고 주장하지 않습니다.

## 문제 정의

득점과 승패는 결과를 보여주지만, 팀이 공을 소유하고 공격을 전개하며 슈팅을 만들고 수비한 방식을 충분히 설명하지는 못합니다. 팀에 하나의 고정된 스타일을 부여하면 경기마다 다른 모습도 가려집니다.

따라서 **개별 경기에서 드러난 팀의 경기 운영 특성**을 공통된 기록으로 유형화하여, 여러 리그와 시즌에 걸쳐 비교 가능한 설명을 만드는 것이 이 연구의 목표입니다.

## 연구 질문

경기기록에서 유형을 도출한 뒤, 각 유형의 특징을 설명하고 리그·시즌별 분포를 비교합니다.

| 질문 | 담당 범위 | 결과물 |
|---|---|---|
| **RQ1. 어떤 유형으로 나뉘는가?** | 분석 단위와 지표를 정하고, 경기기록의 유사성으로 유형을 도출합니다. | 2단계 K-means 군집과 4개 유형 |
| **RQ2. 유형은 무엇으로 구별되는가?** | 지표의 차이를 기술하고, 생성된 군집 라벨을 구분하는 모델을 해석합니다. | 평균·분포 비교, 효과크기, SHAP 해석 |
| **RQ3. 유형은 어디서·언제 나타나는가?** | 확정한 유형의 비중을 리그와 시즌별로 비교합니다. | 리그 내·시즌 내 유형 비율 |

## 데이터

| 항목 | 범위 |
|---|---|
| 리그 | EPL, LaLiga, Bundesliga, Serie A, Ligue 1 |
| 시즌 | 2019/20–2024/25 |
| 한 행의 의미 | 한 경기에서 한 팀의 기록. 유지된 경기당 두 행 |
| 분석 표본 | **팀-경기 21,394행 / 서로 다른 리그–경기 ID 10,697개** |
| 저장 데이터의 날짜 | 2019-08-09–2025-05-25 |
| 논문에 기재된 출처 | Sofascore, Understat(PPDA·DEEP) |
| 군집 입력 | 14개 지표. 득점·경기 결과·xG는 군집 입력에서 제외 |

경기 수는 실제 저장 데이터에서 집계했고, 두 팀의 상대명·점수 관계도 확인했습니다. **전체 일정의 모든 경기를 수집했다는 뜻은 아닙니다.** 수집 원본과 제공처 간 결합 이력은 이번 검토에서 복원하지 않았습니다. 정제 입력과 군집 라벨 CSV를 포함했습니다. 원본 수집 응답과는 구분하며, [데이터 안내](data/README.ko.md)에서 파일과 지표 설명을 볼 수 있습니다.

## 분석 방법

1. 대상 6시즌을 선택하고 14개 지표가 모두 있는 행을 남깁니다.
2. 단위가 다른 지표를 표준화하고, PCA(여러 지표의 변동을 적은 수의 축으로 요약하는 방법)로 2차원 좌표를 만듭니다.
3. 1차 군집 수 `k=2…9`를 비교합니다. 선택한 2개 상위 군집 안에서 각각 `k=2…5`를 검토한 뒤 2개씩 나눕니다.
4. 원래 지표의 평균을 비교하여 4개 군집에 사후적 해석명을 붙입니다.
5. 기술통계·Mann–Whitney U 검정·효과크기로 차이를 살피고, 트리 기반 분류 모델과 SHAP으로 라벨 구분을 설명합니다.
6. 리그와 시즌별 유형 비중을 비교합니다.

이 절차는 **K-means를 2×2로 반복하는 분할**입니다. 응집형 계층적 군집분석이나 전체 표본에서 최적 `k=4`를 바로 선택하는 방식과 구별해야 합니다. 기존 RQ1 저장 출력에서 PCA 두 축의 설명분산은 45.95%이며, 이번에는 PCA를 다시 학습해 확인하지 않았습니다.

## 현재 저장 데이터에서 확인한 결과

아래 수치는 기존 라벨 CSV를 다시 집계한 값입니다. 군집 모델은 재학습하지 않았습니다. 4개 군집의 14개 지표 평균은 논문 표 7의 소수점 둘째 자리까지 모두 일치합니다.

| 유형 | 해석명 | 팀-경기 수 | 비중 | 점유율(%) | 슈팅 | PPDA |
|---|---|---:|---:|---:|---:|---:|
| 1-1 | 점유 전개형 | 6,487 | 30.32% | 56.48 | 14.42 | 9.85 |
| 1-2 | 고점유 지배형 | 2,855 | 13.34% | 65.50 | 19.98 | 8.22 |
| 2-1 | 저점유 수비형 | 4,122 | 19.27% | 35.60 | 7.82 | 20.59 |
| 2-2 | 수비적 전개형 | 7,930 | 37.07% | 46.60 | 10.70 | 12.33 |

- 고점유 지배형은 평균 슈팅이 가장 많고 PPDA가 가장 낮습니다. 낮은 PPDA는 상대적으로 강한 압박 활동을 시사하는 간접 지표이며, 압박 성공을 입증하지 않습니다.
- 저점유 수비형은 적은 슈팅과 많은 클리어링이 함께 나타납니다. 관찰된 기록의 특징이지, 모든 경기에서 의도적으로 수비 전술을 선택했다는 증거는 아닙니다.
- 고점유 지배형 비중은 EPL 표본에서 **17.13%**, LaLiga에서 **10.82%**입니다. 보정하지 않은 표본 비율로 리그 수준의 우열을 판단하지 않습니다.
- 시즌과 유형의 연관성을 다시 계산한 **Cramér's V는 0.0482**입니다. 이 값은 연관성의 크기를 나타냅니다. 작은 p값만으로 큰 실질적 변화를 주장하면 안 되며, 같은 팀의 반복 관측과 같은 경기의 두 팀 기록이 포함된다는 점도 고려해야 합니다.

### 논문과 저장 데이터의 차이

논문 표 8(본문 24쪽, PDF 33쪽)은 2-1·2-2 군집을 **4,017·8,035건**, 현재 CSV와 선택한 노트북의 저장 출력은 **4,122·7,930건**으로 제시합니다. 전체 21,394건은 같습니다. 원인은 아직 확인되지 않았으며, 이 차이만으로 ‘특정 105경기의 라벨이 바뀌었다’고 판단할 수 없습니다. 논문 수치나 원본 파일을 임의 수정하지 않았습니다. [상세 대조 기록](docs/VALIDATION.md)에 남겼습니다.

## 활용과 의미

비슷한 경기 사례를 찾거나 상대팀을 탐색적으로 비교하고, 영상으로 확인할 가설을 만드는 데 활용할 수 있습니다. 같은 팀도 경기별로 다른 유형에 속할 수 있습니다. 특정 유형이 승리를 만든다거나 감독이 선택해야 할 최적 전술이라는 결론은 내리지 않습니다.

## 한계

- 군집을 만든 지표로 군집 라벨을 다시 설명합니다. 분류 정확도는 라벨 복원 능력이며, 외부에서 검증된 전술의 정답이나 승패 예측 성능이 아닙니다.
- 기존 RQ2 코드는 테스트 F1로 최종 모델을 선택합니다. 따라서 해당 테스트셋은 모델 선택에 이미 사용되었으며, 독립된 최종 평가셋으로 볼 수 없습니다. PCA와 군집도 분할 전에 전체 자료에서 도출되었습니다.
- 무작위 행 분할은 미래 시즌·새로운 팀·같은 경기의 상대팀을 분리하지 않습니다. 반복 관측 자료에 통계 검정을 적용할 때 독립성 가정에 주의해야 합니다.
- 군집 입력 지표에 대한 차이검정은 사후 기술적 비교입니다. 군집이 실제로 존재한다는 독립적인 검증으로 해석하지 않습니다. 다중비교와 효과크기도 검토해야 합니다.
- PCA 두 축은 원 지표 변동의 일부만 보존합니다. 차원이 다른 공간에서 실루엣이 높다고 축구 유형의 타당성이 증명되는 것은 아닙니다.
- 점유율·상대 수준·홈/원정·스코어 상황·제공처 차이를 보정하지 않았습니다. 14개 지표는 서로 연관되며 모든 전술 국면을 포괄하지 않습니다.
- 전체 수집 과정과 노트북 재실행, 논문 사례 수 불일치 해소는 남은 과제입니다.
