# 공개 저장소 준비와 파일 판단

## 권장 저장소

추천 이름은 **`football-match-profiles`**입니다. 석사 연구는 질문·논문·실행 순서가 독립적이므로 별도 저장소로 관리하고, 기존 `all-sports-analytics`에는 연구 소개와 링크만 추가하는 구성을 권장합니다. 통합 저장소를 선호한다면 같은 패키지를 `football/match-record-profiles/` 아래에 둘 수도 있습니다. 이 패키지는 독립 연구 저장소로 공개하며, 기존 통합 저장소와는 별도로 관리합니다.

README의 제목은 실제 측정 범위인 경기기록 유형을 강조하고, 원 논문 제목은 출처에 그대로 남겼습니다. 연구 질문과 분석 범위는 [문제 정의 문서](PROBLEM_DEFINITION.md)에 정리했습니다.

## 판단 원칙

1. 논문 RQ1–RQ3를 설명하거나 실행하는 데 직접 필요한가?
2. 선택한 입력·라벨 기준과 연결되고 논문의 값과 비교할 수 있는가?
3. 같은 역할의 다른 파일보다 기준 버전으로 삼을 근거가 있는가?
4. 다른 사람의 자료·개인 설정·재생성 가능한 바이너리를 불필요하게 공개하지 않는가?

‘빼기’는 원본 삭제가 아니라 **공개 패키지에서 제외하고 로컬 보존**한다는 뜻입니다. 파일명 `최종`, `FINAL`, 수정일만으로 선택하지 않았습니다.

## 212개 원본 파일의 분류

압축 파일은 하나의 파일로 집계했으며 ZIP 내부의 개별 파일은 검사하지 않았습니다. 따라서 아래 수치는 폴더의 일반 파일 212개에 대한 전수 목록입니다.

| 처리 | 파일 수 | 판단 |
|---|---:|---|
| 참고용 코드 사본 포함 | 3 | 사용자 지정 RQ1/RQ2/RQ3. 출력 제거, 재현 미검증 명시 |
| 분석 데이터 사본 포함 | 2 | 정제 CSV와 최종 라벨 CSV. 원본과 동일한 사본·해시·지표 사전 포함 |
| 과거 분석·중간 데이터 로컬 보관 | 23 | 다른 지표 수·기간·대안 질문을 섞지 않음 |
| 기존 CSV 재생성 대상으로 분류 | 57 | 여러 실행본의 결과가 섞여 있음. 현재 리뷰 집계로 일부 대체 |
| 기존 그림 재생성 대상으로 분류 | 71 | 구명칭·중복·FINAL 버전 혼재. 전부 업로드하지 않음 |
| 외부 참고문헌 PDF 제외 | 31 | 본문 PDF 대신 확인된 서지정보와 링크를 이후 정리 |
| ZIP 제외 | 3 | 중복 아카이브를 공개 실행 경로에 포함하지 않음 |
| 모델 바이너리 제외 | 5 | 재생성 가능하고 환경·계보가 미확정 |
| OS·개인 도구·잘못 생성된 경로 제외 | 15 | `.DS_Store`, `.claude` 등 |
| 작업 메모·HTML 제외 | 2 | 독자가 따라갈 연구 실행 경로에서 제외 |

각 파일의 실제 상대경로·용량·SHA-256·판단 이유·사본 목적지는 **[FILE_DECISIONS.csv](FILE_DECISIONS.csv)**에 있습니다. 파일 내용이 완전히 같은 5개 묶음은 [DUPLICATE_FILES.json](DUPLICATE_FILES.json)에 기록했습니다. 의미상 중복과 바이트 단위 중복은 다릅니다.

## 데이터 판단

- `tactical_analysis_cleaned.csv`: RQ1이 실제 읽는 21,394행·56열 입력입니다. 군집에는 그중 14개 지표만 사용합니다.
- `rq1_final_data_14vars_hierarchical_4clusters.csv`: RQ2·RQ3 입력이 되는 21,394행·30열 파일입니다. 논문과 사례 수가 다른 현재 스냅샷임을 구분해야 합니다.
- `master_5leagues_long_clean.csv`, `tactical_analysis_final_16vars.csv`, `tactical_analysis_with_xG*.csv`: 확인된 일반 파일들은 25,066행이며 2018년부터 시작합니다. 최종 연구의 6시즌·14지표 입력과 섞지 않습니다. 더 크거나 이름이 `final`이라고 기준 입력은 아닙니다.
- `data/raw`에는 이번에 확인 가능한 일반 파일이 없었습니다. 제공처 원자료→통합→정제 과정의 전체 재현은 추가 작업입니다.

사용자 요청에 따라 두 필수 입력의 동일한 사본을 포함했습니다. 카테고리별 데이터 안내에는 각 컬럼의 뜻·단위·군집 사용 여부·결측·값 범위와 리그·시즌별 기간을 정리했습니다. 제공처의 수집 원본 응답은 확보하지 못했으며, 제공처의 재배포 조건 확인은 아직 수행하지 않았습니다.

## 논문과 그림

- 사용자 논문 PDF는 휴지통의 지정 경로에서 읽기만 했습니다. 논문을 자동으로 공개하거나 이동하지 않았습니다. 이후 공개하려면 인준 페이지·서명 등 불필요한 내용을 검토한 공개용 사본을 별도로 정할 수 있습니다.
- 외부 논문 PDF 31개는 저장소에 넣지 않습니다. 참고문헌 목록은 제목만으로 DOI를 추정하지 말고 실제 출처 확인 후 작성합니다.
- 첫 정식 결과 그림은 군집별 지표 비교, PCA 유형 지도, 리그별 유형 비중, 시즌별 비중 중 3–4개면 충분합니다. RQ2 모델·라벨 기준을 재확정한 뒤 SHAP 그림을 추가합니다.
- 현재 공개 준비본은 기존 그림을 임의로 ‘대표 결과’로 선택하지 않았습니다. README의 수치는 새 리뷰 CSV로 연결했습니다.
